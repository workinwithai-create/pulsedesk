# PulseDesk

Focused drum + bass groove desk for producers who struggle with stiff rhythms and finishing the rhythm section.

## Features
- Your BPM (60-180) and key first
- Live drum and bass samples
- Proper lookahead scheduler on AudioContext clock
- Live changes apply on next step
- Grid-accurate WAV and MIDI exports (48kHz, 24-bit, exact length, first transient at sample 0, tail folded)
- localStorage persistence
- Mute per chair
